## ПРАВИЛО ДВОЙНОГО ЗЕРКАЛЬНОГО ХРАНЕНИЯ

Каждый файл живёт **в двух местах одновременно**:

1. **Проектная файловая структура** (эта папка — как репозиторий).
2. **Google Drive**, папка `ИЛЛЮМИНАНТ`.

**Написал главу или изменил управляющий файл — сохраняй в оба места СРАЗУ, в тот же заход.** Не «потом», не «в конце сессии». Расхождение между зеркалами — это и есть источник путаницы.

## СТРУКТУРА ПАПОК

```
ИЛЛЮМИНАНТ/
├── CLAUDE.md · README.md · 01…08_*.md      управляющие файлы, всегда в корне
├── КНИГА_I/
│   ├── ФИНАЛ/            утверждённые автором главы
│   └── РАБОЧИЙ_СТОЛ/     версии в работе: v1, v2, v3, v10
├── ИСТОЧНИКИ/            авторские старые версии, только чтение
├── АРХИВ/                всё вышедшее из обращения
└── old version/          (на Drive) прежняя папка BOOKS/Иллюминант целиком
```

**ФИНАЛ и РАБОЧИЙ СТОЛ разделены жёстко.** В ФИНАЛ файл попадает только после того, как автор его утвердил. До этого — рабочий стол, сколько угодно версий.

## ИМЕНОВАНИЕ

| Что | Шаблон |
|---|---|
| Управляющий файл | `NN_НАЗВАНИЕ.md` |
| Глава-финал | `Глава_NN_Название.md` |
| Черновик | `Глава_NN_Название_vN.md` |

Номер главы — всегда две цифры. Вместо пробелов — подчёркивания. Никаких «(ФИНАЛ)» в скобках и никаких «Книга I —» в начале имени: папка уже говорит, где файл лежит.

## ФАЙЛ ОДИН

Один канон — один файл `02_КАНОН.md`, и он **обновляется**, а не размножается. Один глоссарий. Одна библия персонажей. Один файл заметок, а внутри него разделы «Глава 1», «Глава 3».

Файл, который больше не действует, **не удаляется** — переезжает в `АРХИВ/`. Удаление — только с прямого подтверждения автора.

## ЖУРНАЛ

В конце каждой сессии — запись в `06_РЕЕСТР_И_ЖУРНАЛ.md`: зашёл, что сделал, что осталось, где сошли с рельсов. Без этой записи сессия не считается закрытой.
