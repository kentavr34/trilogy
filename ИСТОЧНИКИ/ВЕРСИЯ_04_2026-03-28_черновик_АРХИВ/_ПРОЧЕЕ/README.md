# Иллюминант — финальная версия трилогии

Этот репозиторий содержит **канонические документы** и **итоговые главы** трилогии «Иллюминант».  
Здесь нет старых черновиков — только финальный план и чистовая работа.

## 📁 Структура

- [`CANON/`](CANON) — неизменяемые основы проекта:
  - `WORLD_BIBLE_MASTER.md` — трёхуровневое развитие героя.
  - `STYLE_CODEX.md` — стиль (Стивен Кинг + фильм «Константин»).
  - `TRILOGY_SCENE_SKELETON.md` — структура всех книг с тезисами глав.
  - `WORKFLOW_PROTOCOL.md` — 100% система проверки каждой главы.
  - `RECOMMENDATIONS_FOR_MAX_POTENTIAL.md` — как усилить до бестселлера.
  - `PROJECT_STATE_CHECKPOINT.md` — **главный файл для AI-помощника**. Прочитав его, любой новый помощник мгновенно войдёт в курс дела.
- [`FINAL_BOOK_OUTLINE.md`](FINAL_BOOK_OUTLINE.md) — полный план всех трёх книг: глава за главой, с кратким содержанием, тезисами и ссылками на исходники.
- [`FINAL_BOOKS/`](FINAL_BOOKS) — сюда будут помещаться новые чистовики глав по мере написания:
  - `BOOK_1/` (Книга 1)
  - `BOOK_2/` (Книга 2)
  - `BOOK_3/` (Книга 3)

## 🚀 Как продолжить работу (для человека или AI)

1. **Прочитайте `CANON/PROJECT_STATE_CHECKPOINT.md`** — это снимок состояния проекта и ключевые решения.
2. **Ознакомьтесь с `FINAL_BOOK_OUTLINE.md`**, чтобы понять, какая глава пишется следующей.
3. **Следуйте `WORKFLOW_PROTOCOL.md`** при написании каждой главы.
4. После утверждения главы автором — переместите её в соответствующую папку `FINAL_BOOKS/BOOK_X/` и отметьте как готовую в структуре.

- **Книга 2 и Книга 3** — только тезисы. Написание начнётся после завершения Книги 1.
