# ТРИЛОГИЯ «ИЛЛЮМИНАНТ» — НОВАЯ ВЕРСИЯ (пишется с нуля)

> Чистая рабочая папка. Здесь мы с автором пишем трилогию **заново, с чистого
> листа**, по единому канону и авторскому стилю. Всё прежнее (папка `claude/` в
> корне репозитория) — **архив**, не источник финального текста (только как
> справка о ранее написанном).

## Структура

- **`00_КАНОН/`** — Библия мира, каноны, сквозная хронология, авторский стиль,
  единое видение трилогии, беаты книг, памятка о религии и хронологии.
  Читать перед написанием любой главы.
- **`Книга_I_Источник_Света/`** — Книга I (ступень: ЛЮБОВЬ). Пишется.
- **`Книга_II_Воин_Света/`** — Книга II (ступень: МУДРОСТЬ).
- **`Книга_III_Лучезарный/`** — Книга III (ступень: СМИРЕНИЕ).
