## ЧАСТЬ 1. РЕЕСТР ФАЙЛОВ

### Правило именования (единое, нарушать нельзя)

| Что | Шаблон | Пример |
|---|---|---|
| Управляющий файл | `NN_НАЗВАНИЕ.md` | `02_КАНОН.md` |
| Глава-финал | `Глава_NN_Название.md` | `Глава_07_Одно_слово.md` |
| Черновик главы | `Глава_NN_Название_vN.md` | `Глава_14_Психиатр_v2.md` |
| Архив | внутри `АРХИВ/`, имя не меняется | — |

Номер главы — всегда **две цифры**. Пробелы в именах — подчёркивания. Никаких «(ФИНАЛ)» в скобках, никаких «Книга I —» в начале: папка уже говорит, книга это или архив.

### Дерево проекта

Актуальный диспетчер файлов — в корневом `CLAUDE.md` (раздел «ДИСПЕТЧЕР ФАЙЛОВ ПРОЕКТА»).
Кратко: корень = CLAUDE.md + README + `RULES/` (управляющие 01–08, ОСИ/, ЧАТ_ДИАЛОГ, архив чатов) +
`КНИГА_I_ФИНАЛ/` (главы 1–13 md + DOCX/) + `РАБОЧИЙ_СТОЛ/` + `ИСТОЧНИКИ/` +
`OLD/` (Книга_1/2/3 — все старые версии глав «Глава NN - Название - vK - дд.мм.гггг»; датированные папки март/апрель/облако).
