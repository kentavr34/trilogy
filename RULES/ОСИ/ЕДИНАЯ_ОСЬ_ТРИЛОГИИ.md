# ИЛЛЮМИНАНТ — ЕДИНАЯ ОСЬ ТРИЛОГИИ (мастер-структура)

Согласованный сквозной позвоночник всех трёх книг. Отменяет разнобой прежних версий. Имена:
Михаил, Ева, Лили/Лилит, Пётр, Одсэр, Иоган, Ахмет, Афина. Место: Лондон (+ Париж, Тибет,
США, Ватикан, ад). Год Кн. I — 2023 (Михаил 33; шрам «23 года»; рождение ~1990).

---

## 0. БИБЛИЯ МИРА (законы)
- Любовь — сила Первоисточника (ты лишь проводник); высшее — милосердие (Ар-Рахман). Вера
  без любви = фанатизм; Вера+Любовь = непобедимость.
- Победа над демоном: заглянуть в глаза, любить — и назвать по имени. Без любви ни крест, ни
  вода не берут.
- ЗАКОН ПРОКЛЯТИЯ: проклясть = «молитва наоборот» → рвёт нить душа-Бог → открывает демонам.
  Грех/чувство ≠ одержимость, пока не проклянёшь.
- Тень греха ≠ одержимость (одержимость — после проклятия).
- Ангел: природа ≠ сила (может отдать силу, стать смертным, оставаясь ангелом по сути).
- Тело самоубийцы принадлежит демону; экзорцизм «во имя Бога» бессилен.
- Амулет Повелителя Времени переносит лишь светлых; «Повелитель Времени» — миссия, эстафета.
  Печать ада — взлом: демоны едут, слившись со светлым носителем.
- Клинок Авраама (+ копия): единственное поражение Люцифера от любви смертного «из глины».
- «ЛЮЦИФЕР» — ДОЛЖНОСТЬ, не персона. Побеждающий силой любви становится следующим Лучезарным.
  Одсэр — прежний носитель (наставник и испытатель), растит преемника.
- Время — замкнутая петля (предопределение); прошлое не изменить.
- СЕМЁРКА: 7 грехов = 7 архидемонов = 7 нот = 7 цветов радуги; каждый демон правит грехом и
  эмоцией; 7 воинов-антиподов с талантами-цветами.

## 2. КНИГА I «ИСТОЧНИК СВЕТА» — любовь
АКТ I — Травма: парк (амулет Петру, мальчик); 23 года спустя Михаил 33, триумф+Лили+отказ;
ночь, скрип двери → флешбэк №1 (одержимый отец убивает мать и гонится за Михаилом, без
раскаяния); детдом, Пётр; «шрам на сердце».
АКТ II — Грехи, Ева, крах: шесть пациентов (Матвей-зависть, Ангелина-уныние, Андрей-гнев,
Магдалена-алчность, Исав-чревоугодие, Гавриил-гордыня); Афина знает раньше; знакомство с
Евой (книжный/Вербер + выставка); Лили(Асмодей) ↔ Ева. Гавриил проклял → одержим → суицид →
крах карьеры.
АКТ III — Катарсис: мечеть (Пётр+Али, закон проклятия) → бег → флешбэк №2 (добрые кадры об
отце → отец проклял коллег → одержим; «я не проклинал» → демон убил мать) → могила матери →
мать-жертва войны → прощение.
АКТ IV — Любовь наполняет: дача, уныние, Маммон → Ева находит его; кафе (Афина поёт «Любовь
настала» → «Ave Maria», «галлюцинации?»); такси (Ева исцеляет Жанну); Ева уезжает, «повод
остаться?» — молчит; лицензию вернули → «мне пора» → Ева уходит.
АКТ V — Первая победа: бар, Лили; реальные демоны; уборная → письмо Евы → слова Петра →
«Асмодей» → первая победа.
АКТ VI — Опасность, жертва, склеп: Ева в опасности → авария → заплыв → «умерла» → воскрешение
(душа-ангел тратит силу → смертна) → Центр «Источник Света» → склеп: Люцифер в теле
самоубийцы Гавриила; Лили выбирает тьму → Лилит; Люцифер+Лилит в портал.

## 3. КНИГА II «ВОИН СВЕТА» — мудрость
Маршрут Лондон→Париж→Тибет→США. Расцвет Центра, гордыня; Ева-провидица просит остановиться.
Париж: демон раздора (ревнующая Лилит) убивает Еву (Сена) — необратимо. Михаил на грани
проклясть — удерживается. Центр прогнил → бросает всё. Тибет: Одсэр раскрывает суть амулета,
даёт два клинка; истории; «магия ≠ мудрость». США: культ Освобождение/Маммон; Элендиэль,
древние светлые сущности, армия. Асмодей держит душу Евы. Первый штурм силой → падение →
петля №1 (смирение) → армия; Пётр ждёт. Пегас, башня; смерть Петра → ВТОРОЙ КАТАРСИС.
Эльфийские похороны. Замыкание петли (Отрешённый, третий POV). Люцифер в портале; душа Евы в
заложниках.

## 4. КНИГА III «ЛУЧЕЗАРНЫЙ» — смирение
Апокалипсис: Ватикан, семь ангелов. Совет; тайны (Клинок Авраама, Повелитель Времени=миссия,
мать-Иллюминант); жестокое условие о Еве (возвысится, не человеком; билет в один конец) → «не
лучший вариант». Дурман → худшие мгновения разом (гибель матери) → амулет вспыхнул → Маммон
печатью ада → перенос в прошлое. Мать-Иллюминант (защищается сама); отец проклинает коллегу →
одержим; ошибка Михаила (защитил сильную); «Беги» → растворяется. Ярость → решение сойти в
ад и уничтожить Люцифера; билет в один конец. Пресыщение духа (семь воинов). Одсэр применяет
амулет → огненные сущности → ад; семь узлов (дуэли воин↔грех); Лилит во главе демонов
окружает помощников. Асмодей повержен → душа Евы освобождена → Ева рядом. Последнее искушение
(Люцифер манипулирует душой Евы) → Элендиэль («ловушка») → отказ. ПРЕОБРАЖЕНИЕ И ПРЕЕМСТВО:
клинки в пещеру → объятие → оболочка Люцифера растворяется → проступает Одсэр: «теперь твоя
очередь» (Люцифер — должность). ПРОЗРЕНИЕ ЛИЛИТ: смена Лучезарного — критический миг для
элиты; Лилит преклоняет колени, отрекается от зла, клянётся служить высшей цели (тоже
испытательница). Душа Евы восходит к свету — Михаил отпускает. Апокалипсис не наступает.
Эпилог: эстафета звезды, новый цикл.

## 5. СКВОЗНЫЕ АРКИ (посев → всход)
- Роковая ночь ×3-4 POV: Пролог/Пётр → флешбэк/10-летний → Отрешённый (конец Кн. II) +
  прошлое/взрослый (Кн. III).
- Амулет-цикл: Михаил(2000)→Пётр→Михаил(30)→Кн. I–II→Пётр(конец II)→Одсэр(Кн. III).
- Закон проклятия: отец → Гавриил → Михаил (устоял дважды).
- Два катарсиса «отца»: родной (Кн. I) → приёмный Пётр (Кн. II).
- Арка страха/дракона: речь Евы → заплыв (Кн. I) → сошествие в ад (Кн. III).
- Живая вода: исцеление/Центр/«память воды» → в аду вода очищает (Иоган↔Левиафан).
- Ева-ангел: свет → сила потрачена, смертна → гибель, душа в аду → восхождение.
- Лилит: манипулятор → Королева Ада (ревность убивает Еву) → прозрение, служение.
- Семёрка: 6 клиентов + Лили → 7 архидемонов → 7 воинов, 7 узлов.
- «Лучезарный» = должность: намёки → раскрытие в финале.

Мелочи на потом: точные цвета/ноты; искуплённые клиенты в воины; имя друга-хранителя (Хасан?).
